# Coffee House — Landing Page

Учебный проект RS School: адаптивный двухстраничный лендинг кофейни,
свёрстанный по макету [Coffee House](https://www.figma.com/design/yuc5s9NCc4jENkk5LdFfvX/Coffee-House-2026Q3).

## Страницы

- `index.html` — главная: hero, слайдер «Favorite coffee», About, Mobile app, контакты.
- `menu.html` — каталог: категории Coffee / Tea / Dessert и карточки напитков.

## Возможности (Часть 1)

- Семантическая вёрстка на чистых HTML и CSS, без фреймворков.
- Адаптивность от 1440px до 380px, бургер-кнопка на ширине 768px и меньше.
- Светлая и тёмная темы с сохранением выбора в `localStorage`.
- Плавная прокрутка по якорям и hover-состояния у ссылок, кнопок и карточек.

## Возможности (Часть 2)

Вся интерактивность — на чистом JavaScript (ES-модули), без библиотек.

- Бургер-меню на ширине 768px и меньше: выезжает справа под `header`,
  иконка превращается в крестик, прокрутка страницы блокируется.
  Закрывается по ссылке, крестику, `Escape` и при расширении окна до 769px.
- Слайдер «Favorite coffee»: стрелки, индикаторы и свайп, циклическое
  переключение с плавной анимацией.
- Каталог: карточки всех категорий строятся из `data/products.json`,
  категории переключаются без перезагрузки страницы.
- На ширине 768px и меньше сначала показываются 4 карточки и кнопка
  «показать ещё»; при изменении ширины окна режим меняется сам.
- Модальное окно товара (`<dialog>`) строится из того же объекта, что и карточка:
  выбор размера и добавок сразу пересчитывает итоговую цену.

## Структура

```
assets/   изображения и иконки из макета
css/      стили
data/     products.json — данные каталога
js/
  theme.js        светлая / тёмная тема
  burger.js       бургер-меню
  slider.js       слайдер на главной
  menu.js         карточки, категории, «показать ещё»
  modal.js        модальное окно и расчёт цены
  price.js        форматирование цены
  scroll-lock.js  блокировка прокрутки страницы
```

## Локальный запуск

```bash
python3 -m http.server 5500
```

Затем откройте http://localhost:5500/index.html

Страницы нужно открывать через сервер, а не как файл (`file://`):
ES-модули и загрузка `products.json` через `fetch` без него не работают.
